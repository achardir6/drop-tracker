DROP TRACKER — ONLINE + PWA

Özellikler:
- Rare / Big Rare / Epic / Legendary butonları
- Sıralı drop geçmişi
- Toplam ve kategori sayaçları
- Geri Al / Temizle
- Tek tıkla alt alta kopyalama
- iPhone/Android responsive
- PWA (Safari > Paylaş > Ana Ekrana Ekle)
- Yerel mod
- Supabase online senkronizasyonu

ONLINE KURULUM:
1) Supabase'de ücretsiz bir proje oluştur.
2) SQL Editor'a gir ve bu klasördeki supabase.sql dosyasının tamamını çalıştır.
3) Supabase > Project Settings > API bölümünden Project URL ve anon public key değerlerini al.
4) Siteyi HTTPS altında yayınla (GitHub Pages, Netlify, Cloudflare Pages vb.).
5) Sitede 'Online Ayarları'na basıp URL + anon key + bir Tracker Kodu gir.
6) PC ve iPhone'da AYNI Tracker Kodunu kullan. Böylece aynı liste senkron olur.

GÜVENLİK NOTU:
Bu kurulum Tracker Kodunu bilen herkesin o listedeki kayıtları görüp silebilmesine izin verir. Kodu paylaşma. Daha güçlü güvenlik için sonraki sürümde e-posta/şifre veya Google ile giriş eklenebilir.
